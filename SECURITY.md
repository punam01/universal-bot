# Security Policy

## Reporting a vulnerability

**Do not** open a public issue for security vulnerabilities.

Use GitHub's [private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) on this repository.

We aim to acknowledge reports within 72 hours and to issue a fix or mitigation within 30 days for confirmed issues.

## Scope

In scope:
- All code in this repository
- Official container images (once published)

Out of scope:
- Third-party services (Oracle Cloud, Gemini API, Groq, etc.)
- User-deployed instances you do not control
- Dependencies — please report those upstream
