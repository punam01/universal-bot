# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

TL;DR: be respectful, be inclusive, assume good intent, call out harm kindly.

Report unacceptable behavior via GitHub's private vulnerability reporting on this repo, or open an issue with the `conduct` label if the matter is not sensitive.
